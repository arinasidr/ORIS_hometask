Формат общего сообщения:
1. type - тип сообщения (ниже список типов)
2. from_user - имя пользователя или none в случае системных сообщений
3. room_id - номер комнаты или none 
4. data - данные сообщения

Список типов сообщений:
1. signup 
2. join_room 
3. room_update 
4. chat 
5. move 
6. game_start 
7. state_update
8. game_over
9. disconnect 
10. error
ВОЗМОЖНЫ ДОПОЛНЕНИЯ ПРИ НЕОБХОДИМОСТИ 


1. signup 
отправляет: клиент - сервер
зачем: регистрация игрока на сервере
data: имя игрока (тип: строка)

2. join_room
отправляет: сервер - клиент
зачем: сообщить игроку номер комнаты
data: номер комнаты (тип: число)

3. room_update
отправляет: сервер - клиент
зачем: обновление информации о комнате
data: список игроков (['Player1', 'Player2']), статус комнаты waiting\playing\game_over

4. chat
отправляет: сервер - клиент, клиент - сервер
зачем: сообщение в чате комнаты
data: текст сообщения (тип: строка)

5. move
отправляет: клиент - сервер
зачем: попытка сделать ход
data: направление вверх\вниз\вправо\влево {'direction' : 'up'}...

6. game_start
отправляет: сервер - клиент
зачем: сигнал начала игры
data: стартовые позиции игроков {Player1 : (10, 15)}, цвета игроков {Player1 : pink}

7. state_update
отправляет: сервер - клиент
зачем: обновление игрового поля
data: матрица 15*15, позиции игроков, блокировки, бонусы
- board:  матрица 15*15 (каждая клетка - имя игрока или none)
- players: словарь {Player1: (x, y)}
- blocked: словарь {Player1: time}
- bonuses: список бонусов [(type, x, y)] 

8. game_over
отправляет: сервер - клиент
зачем: сигнал завершения игры
data: победитель (тип: строка), статистика (процент территории, время игры)

9. disconnect
отправляет: клиент - сервер
зачем: игрок отключается
data: none

10. error
отправляет: сервер - клиент
зачем: оповещение об ошибке
data: сообщение ошибки (тип: строка)
